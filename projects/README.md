# projects/

Your projects live here (`<slug>.ae1proj` + `<slug>/{scenes,scripts,media}`). Open the
editor and click **New Project** — the Wizard scaffolds one.

**`starter/`** is a minimal, fully original 3D scene to learn from and build on: a
checker floor, a third-person player body (WASD / arrows move, mouse orbits, Space
jumps, Shift runs), a sun light, the input controller, and a spinning crate. Every
asset in it was generated by `meshforge.py` from a few lines of JSON — no game assets.
Copy it, or just start editing.

AE1 ships **no game assets**. Bring your own, or generate original ones with the
forges in the repo root: `meshforge.py` (props), `clipforge.py` (mechanical
animation), `audioforge.py` (speech). Per-project media blobs are git-ignored by
content hash (only `manifest.json` is tracked) — the starter's three tiny generated
glbs are the one deliberate exception.
